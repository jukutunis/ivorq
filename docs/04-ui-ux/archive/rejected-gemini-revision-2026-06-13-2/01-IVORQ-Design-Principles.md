# 01. IVORQ Design Principles

## Core Philosophy
IVORQ is designed as a **Modern Hospitality Command Center**, deliberately moving away from legacy software aesthetics.

### 1. Operationally Focused
- Surfaces critical information immediately (Command Center layout).
- Minimizes clicks required for common operational tasks.

### 2. No "AdminLTE" / No "CRUD" Feel
- We reject the standard "left sidebar + data table" CRUD interface.
- Data is presented in tailored, card-based workspaces rather than generic admin grids.
- Dashboards feel like operational pulse-checks, not database management tools.

### 3. Crisp, Professional Aesthetics
- Relies on ample whitespace, clean typography, and purposeful use of color.
- No outdated ERP colors; leverages a modern, sophisticated palette centered around IVORQ Navy (`#1A2356`).

### 4. Clarity over Density
- Information hierarchy guides the user's eye to what needs attention.
- Uses badges, color-coding, and clear typographics to communicate status.
