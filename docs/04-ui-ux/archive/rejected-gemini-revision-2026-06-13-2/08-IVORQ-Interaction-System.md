# 08. IVORQ Interaction System

## User Interactions

### Hover States
- Buttons, links, and table rows must have clear, immediate hover states (usually a slight background color shift or opacity change) to indicate interactivity.
- Action buttons within table rows are often revealed or intensified on row hover to reduce visual clutter when scanning data.

### Drawers over Modals
For complex data entry or detailed record viewing (e.g., viewing full details of a Work Order or Room Inspection):
- **Slide-out Drawers** (originating from the right edge) are preferred over center-screen Modals.
- Drawers preserve the user's context of the background workspace while providing ample vertical space for forms and logs.

### Feedback
- **Toasts**: Used for non-blocking success/error notifications (e.g., "Reservation Saved"). Appears at the top right or bottom right.
- **Inline Validation**: Form errors appear immediately below the respective input fields in semantic Red.
