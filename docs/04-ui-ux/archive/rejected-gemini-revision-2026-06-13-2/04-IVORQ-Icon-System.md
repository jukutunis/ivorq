# 04. IVORQ Icon System

## Icon Library
**Lucide Icons**
We utilize the Lucide icon set (the modern standard replacing Feather icons) for all iconography within IVORQ.

## Design Rules
1. **Stroke Width**: Consistent `2px` stroke width for all icons.
2. **Style**: Outline style only (no solid/filled icons, except where explicitly required for distinct active states, though outline is preferred).
3. **Sizing**:
   - **Micro (12px)**: Used inside badges or next to metadata.
   - **Standard (16px)**: Used in buttons, dropdown menus, and standard lists.
   - **Navigation (20px)**: Used in the top module navigation bar.
   - **Hero/KPI (24px - 32px)**: Used in dashboard metrics and empty states.

## Operational Mapping
- **Front Desk / Guest**: `users`, `user-check`, `user-minus`, `key`
- **Housekeeping**: `sparkles`, `brush`, `bed`, `clipboard-list`
- **Engineering**: `wrench`, `tool`, `alert-triangle`, `clock`
- **Inventory**: `package`, `boxes`, `arrow-down-to-line`
- **Finance**: `dollar-sign`, `pie-chart`, `trending-up`
