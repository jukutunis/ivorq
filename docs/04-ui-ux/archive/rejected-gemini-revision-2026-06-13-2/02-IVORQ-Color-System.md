# 02. IVORQ Color System

## Core Identity
IVORQ's identity is anchored in a sophisticated Navy, establishing trust, professionalism, and a modern hospitality feel. We strictly avoid legacy ERP/Admin panel color schemes.

### Primary Colors
- **IVORQ Navy (Primary 900)**: `#1A2356` — Used for top navigation, primary brand moments, and critical structural elements.
- **Primary 500**: `#4F6BED` — Used for primary buttons, active states, and interactive highlights.
- **Primary 50**: `#EEF2FF` — Used for subtle interactive backgrounds (e.g., hover states on rows).

### Neutral Palette (Surfaces & Text)
- **Surface Page**: `#F4F6F8` — The background color of the main application area.
- **Surface Card**: `#FFFFFF` — The background for all content cards, modals, and drawers.
- **Text Primary**: `#1F2937` (Neutral 800) — Main readable text.
- **Text Secondary**: `#6B7685` (Neutral 500) — Metadata, subtitles, and less critical information.
- **Borders**: `#E8ECF0` (Neutral 100) — Dividers and card borders.

### Semantic Colors
Used specifically to communicate state, priority, and operational urgency.

- **Success**: `#10B981` (Background: `#ECFDF5`) — Checked-in, clean, completed, positive metrics.
- **Warning**: `#F59E0B` (Background: `#FFFBEB`) — Due-in, dirty, pending, SLA risks, attention needed.
- **Danger**: `#EF4444` (Background: `#FEF2F2`) — Out of order, critical incidents, overdue.
- **Info**: `#3B82F6` (Background: `#EFF6FF`) — Informational metrics, assigned tasks.
