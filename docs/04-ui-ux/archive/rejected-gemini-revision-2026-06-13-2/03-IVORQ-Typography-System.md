# 03. IVORQ Typography System

## Primary Font Family
**Inter** (Google Fonts)
`font-family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;`

Inter is chosen for its exceptional legibility on digital screens, clean modern aesthetic, and versatility across dense data tables and large command-center numbers.

## Font Weights
- **Regular (400)**: Used for body text, table data, and standard UI elements.
- **Medium (500)**: Used for secondary headings, table headers, and emphasized metadata.
- **Semi-Bold (600)**: Used for card titles, button labels, and primary navigation.
- **Bold (700)**: Used for large KPI numbers, executive dashboard headings, and critical alerts.

## Typographic Scale
- **KPI/Hero**: `24px` to `32px`, Bold. Used for operational snapshots and major metrics.
- **Page Title**: `20px`, Semi-Bold.
- **Card Title**: `16px`, Semi-Bold.
- **Body / Primary Data**: `14px`, Regular.
- **Metadata / Secondary**: `12px` to `13px`, Regular or Medium.
- **Micro / Badges**: `11px` to `12px`, Semi-Bold, uppercase for status badges.
