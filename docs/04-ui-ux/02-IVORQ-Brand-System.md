# 02. IVORQ Brand System

## Brand Identity

**IVORQ** — pronounced "ivory-q" — represents the intersection of hospitality elegance and operational intelligence.

## Brand Personality

| Trait | Expression |
|-------|-----------|
| Premium | Executive-grade design, refined spacing, no visual clutter |
| Calm | Muted surfaces, minimal color accents, quiet typography |
| Operational | Every element serves a workflow purpose |
| Intelligent | Smart defaults, contextual actions, operational awareness |
| Hospitality | Warm but professional, guest-centric language |

## Brand Voice

- Use hospitality terminology: "Guest", "Arrival", "Departure", "Room Status", "Shift Handover"
- Avoid developer terminology: "Record", "Entity", "CRUD", "Database", "Model"
- Action labels should reflect operations: "Start Check-In", "Assign Room", "Approve PR"
- Never: "Create Record", "Edit Entry", "Delete Item"

## Logo Treatment

- **IVORQ** is always displayed in bold, uppercase, with `letter-spacing: 2px`
- Placed in the top-left corner of the navy navigation bar
- Color: Pure white on navy background
- No tagline in the navigation — the product speaks for itself

## Brand Mark

The IVORQ brand mark is typographic only. No icon or symbol accompanies the wordmark in the primary navigation.
