# 05. IVORQ Icon System

## Icon Library

**Lucide Icons** — the modern continuation of Feather Icons.

Lucide provides a comprehensive, visually consistent icon set with clean 2px strokes that align with IVORQ's minimal and elegant aesthetic.

## Sizing

| Context | Size | Usage |
|---------|------|-------|
| Navigation | 18px | Top navigation module icons |
| Section Header | 16px | Card headers, board column headers |
| Inline | 14px | Within buttons, queue items, metadata |
| Badge/Micro | 12px | Inside status badges, counters |

## Stroke

All icons use `stroke-width: 2` consistently. No filled icons except where an active/selected state requires visual distinction.
