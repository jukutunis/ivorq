# IVORQ Hotel Operations Platform

Version: 1.1

Status: Active Development

Owner: IVORQ Technologies

---

# Overview

IVORQ adalah Hotel Operations Platform yang dirancang untuk mengelola seluruh operasional hotel dan resort dalam satu sistem terintegrasi.

Platform ini dibangun menggunakan pendekatan:

* Modular Monolith
* Domain Driven Design (DDD)
* Event Driven Architecture
* Multi Property Architecture

---

# Vision

Menjadi platform operasional hotel modern yang mengintegrasikan seluruh proses operasional, keuangan, sumber daya manusia, dan pengalaman tamu dalam satu ekosistem.
