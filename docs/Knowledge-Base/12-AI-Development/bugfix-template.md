# AI Instructions

Before fixing any bug:

1. Reproduce the bug
2. Identify root cause
3. Analyze impact
4. Create fix strategy
5. Implement minimal fix
6. Run tests
7. Run regression tests
8. Update documentation

Never skip root cause analysis.

Never apply blind fixes.

Never bypass security rules.

---

# Final Rule

Every bug fix must be traceable, testable, and documented.
